# 学习通助手（自用版）

把「章节测验答题」和「视频进度」两件重复劳动交给脚本做。
所有操作都在你自己的电脑上、你自己的账号下进行，不需要把密码给任何人。

---

## 装之前要准备什么

| 需要 | 说明 |
|---|---|
| Windows 电脑 | 现在这套只在 Windows 上测过 |
| Chrome 浏览器 | 装好就行，不用装任何插件 |
| Python 3.9+ | 安装时记得勾选 **Add Python to PATH** |
| 一个 AI 接口密钥 | 形如 `sk-...`，用来答题。没有的话下面有说明 |

装 Python 依赖（只做一次，在解压后的文件夹里右键「在终端中打开」）：

```
pip install requests websocket-client
```

装完先自检：

```
python 环境自检.py
```

## 首次配置（三处，只做一次）

**第一处：`config.json`** —— 用记事本打开，把 `api.key` 换成你自己的密钥。

```json
"api": {
  "key": "在这里填你自己的密钥"
}
```

> 密钥从哪来：这是 OpenAI 兼容接口的密钥，常见的第三方中转站都有。
> 学校域名已经按本校填好了，不用动。

**第二处：登录**

```
python step0_open.py
```

会弹出一个**全新的 Chrome 窗口**（跟你平时用的那个互不影响）。
在这个窗口里登录学习通，进到你的课程列表。登录一次能管很久。

**第三处：登记课程**

在那个窗口里点进你要处理的那门课（随便点开一章），然后运行：

```
python step1_discover.py
```

脚本会从地址栏自动读出课程号存下来。**每门课做一次**，以后不用再登记。

## 日常使用：五步走

假设课程号是 `268330787`（登记课程时脚本会告诉你）。

### ① 扫一遍这门课有哪些任务

```
python step2_scan.py 268330787
```

它会列出所有章节，并统计「课后习题几个 / 视频几个」。

### ② 做课后习题

```
python step3_quiz.py 268330787
```

一章大约 30–90 秒。已经做完的会自动跳过，中途断了直接重跑就行。

先想试水可以加 `--limit 2` 只做前两章，或 `--dry` 只看状态不答题。

### ③ 导出登录凭证

```
python step4_cookies.py
```

后面刷视频是直接跟服务器对话，不经过浏览器页面，所以要把登录凭证复制一份。

### ④ 提取视频参数

```
python step5_jobs.py 268330787
```

这一步会顺便**自动读出这门课要求的上报间隔**（重要，见下面的注意事项）。

### ⑤ 刷视频

```
python step6_video.py 268330787
```

不下载视频、不真播放，只是按节奏上报进度。
脚本内置了自动降速重试——如果被服务器限速，它会自己换慢参数再来一遍。

想看进度不刷：

```
python step6_video.py 268330787 --state
```

## 三条必须知道的规矩

**1. 上报间隔不能自己调快。**
不同课程要求不一样，报得太勤服务器会把增量丢掉——进度条显示满了，但就是不给你通过。第 5 步会自动读出来，别手动改小。

**2. 别想着靠倍速省时间，没用。**
有效时长按真实流逝时间 1:1 计入。报得再快，位置到了片尾还是得在片尾一分钟一分钟地补，总耗时和 1 倍速一样。默认已改成 1 倍速；想缩短总时间只能加并发路数（`--workers`），但聚合别超过 3 倍。

**3. 连续跑太久会被临时限速。**
表现是「跑到一半突然全都不通过了」。这不是封号，等几小时会自己恢复。脚本会自动降速重试，但最好别一次刷十小时以上。

另外：**电脑别让它休眠**，插上电源，否则跑到一半就断了。

**4. 位置满了但不通过，不要在片尾反复重跑整个视频。**
脚本会自动留在片尾平位补报，直到有效时长补齐，不用管它。如果手动干预，记住别回卷到 0——那等于把已经攒下的时长扔掉。
